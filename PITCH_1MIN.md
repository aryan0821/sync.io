# 🎤 1-Minute Hackathon Pitch: Sync.io

## The Pitch (60 seconds)

**"Developers waste 2-3 hours daily switching between separate systems - GitHub for code, Linear for tasks, Slack for communication, email for external messages, and documents for company knowledge. Each system is isolated, and every question requires checking multiple tools.**

**Sync.io unifies all your separate systems into one. Built with LangGraph agents and MCP tools, it's an AI-powered Slack bot that connects GitHub, Linear, documents, email, and your codebase - giving you instant answers without leaving Slack.**

**Ask 'Create standup notes' - done in 5 seconds, pulling from GitHub, Linear, and user context. Ask 'Should I work on authentication?' - it checks for conflicts across all your systems automatically. Ask 'Find the Q4 roadmap' - instant document retrieval.**

**Using LangGraph agents for intelligent orchestration and MCP tools for seamless integration, it saves 30-40 mins daily per developer and eliminates 50+ tool switches. It's not just a bot - it's the unified layer that connects all your separate systems.**

**Sync.io: The unified layer that connects GitHub, Linear, documents, email, and your codebase - all in one place."**

## Key Points to Emphasize

1. **The Problem**: "Separate systems" - GitHub, Linear, Slack, email, documents are isolated
2. **The Solution**: "Unified layer" - connects all separate systems into one
3. **The Demo**: "Create standup notes" - pulls from multiple systems in 5 seconds
4. **The Impact**: "30-40 minutes saved daily" - concrete benefit
5. **The Tech**: "LangGraph agents and MCP tools" - shows technical depth
6. **The Close**: "Unified layer that connects all your separate systems" - memorable ending

---

## Delivery Tips

- **Start strong**: "Separate systems" - emphasize the fragmentation problem
- **Show, don't tell**: Use specific examples ("Create standup notes" pulls from multiple systems)
- **Build momentum**: Each feature shows unification across systems
- **End with impact**: "30-40 minutes saved daily" - concrete numbers
- **Memorable close**: "Unified layer that connects all your separate systems" - repeat the key phrase
